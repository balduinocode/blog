---
title: "Por que escolhi Python?"
date: "2026-02-4"
---

Quando li o livro "A sabedoria de Charlie Munger", encontrei nele um framework de pensamento valiosíssimo. Uso-o para questões pragmáticas, como qual linguagem de programação aprender. Esse framework chama-se Latticework of Mental Models. Não irei adentrar no conceito, pois já fiz um post explicando-o. Através dele, escolhi a linguagem de programação na qual me debruçaria.

Eu não buscava uma ferramenta qualquer, mas uma que lidasse bem com a mutabilidade do mundo,e principalmente da tecnologia. Usei então alguns modelos mentais como:
- Área de Superfície: Qual linguagem possui um maior oceano para navegar(criar)?
- Canivete Suíço: Qual linguagem seria capaz de fazer todas as coisas razoavelmente bem?
- Princípio de Pareto: Qual linguagem me fornece 80% do resultado buscado com 20% de esforço?
- Efeito Lindy: Qual linguagem tem mais potencial de antifragilidade?

Dentro desses parâmetros, Python foi o campeão com folga. Com a difusão de acesso da Inteligência Artificial, nem poderia ter dúvidas. Afinal eu precisava de adaptabilidade estratégica. Posso criar facilmente qualquer coisa com Python: uma automação, um site, um jogo, um processo de web scraping, etc.
